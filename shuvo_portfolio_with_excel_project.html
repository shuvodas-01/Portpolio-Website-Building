07 / SQL work

Business questions → SQL → answers.

E-commerce analysis query

sales_analysis.sql
SELECT
    product_category,
    COUNT(*) AS orders,
    SUM(revenue) AS total_revenue,
    AVG(revenue) AS avg_order_value
FROM sales
WHERE order_date >= '2026-01-01'
GROUP BY product_category
ORDER BY total_revenue DESC;
